للتثبيت على الكمبيوتر
1) انقل أو نزّل ملف EXE على جهاز Windows 10 أو Windows 11 بمعمارية 64 بت.
2) افتحه وأكمل خطوات التثبيت. التثبيت للحساب الحالي، مع اختصار في سطح المكتب وقائمة ابدأ.
3) افتح «مصحف سميع». لا تحتاج Node أو Xcode أو WebView2 منفصلًا؛ محرك التطبيق موجود داخله.
4) القارئ المحلي متاح دون إنترنت بالروايات السبع، مع البحث والعلامات وحفظ آخر صفحة والوضع الليلي والخطوط الأصلية.
5) أقسام الموقع تعرض تصميم سميع الأساسي، وتحتاج الاتصال حسب محتواها. القارئ المحلي عرض نصي بالروايات الأصلية؛ المصحف المصور الأصلي متاح من قائمة الأقسام.
النسخة x64 لمعالجات Intel وAMD. ليست ملف ماك وليست نسخة ARM64 أو ويندوز 32 بت.
الملف غير موقّع بشهادة ناشر موثّق؛ قد يعرض Windows تنبيهًا عند فتحه. البصمة أعلاه تخص الملف النهائي المرفق.

التذكيرات والأذان
- افتح زر «التذكيرات» داخل التطبيق.
- فعّل ورد القرآن، وأذكار الصباح والمساء، والحديث أو الصلاة حسب رغبتك، ثم اضغط الحفظ.
- إشعار الحديث يحمل النص والمرجع، والضغط عليه يفتح الحديث نفسه محليًا.
- اكتب المدينة والدولة لحساب الصلاة واختر طريقة الحساب المناسبة، ثم نزّل الجدول. يُحفظ جدول ثلاثة أشهر بعد نجاح الطلب.
- 20 صوت مؤذن + تسجيل إضافي للفجر محفوظة داخل البرنامج، مع المعاينة ومستوى الصوت والإيقاف.
- اسمح بإشعارات مصحف سميع في إعدادات Windows. وضع التركيز أو عدم الإزعاج قد يخفي الإشعار.
- إغلاق النافذة بزر X يخفيها إلى أيقونة سميع بجانب الساعة ليستمر التذكير. اضغط الأيقونة لإعادة فتحها.
- خيار «تشغيل سميع عند تسجيل الدخول إلى ويندوز» اختياري ويحتاج النسخة المثبتة.
- اختيار «إنهاء سميع» من القائمة يوقف التطبيق والتذكيرات. التطبيق لا يوقظ جهازًا نائمًا أو مغلقًا.
- إذا تعذر إنشاء أيقونة الخلفية، اترك النافذة مفتوحة؛ يعرض التطبيق رسالة بذلك.

إظهار تحميل ويندوز على الموقع
1) فك ضغط Samee3-Windows-Website-Ready.zip.
2) ضع ملفات التشغيل الخمسة في المسارات التالية داخل جذر مستودع سميع، واستبدل كل ملف كاملًا:
   1. public/app-downloads.json
   2. lib/app-downloads.ts
   3. app/api/app-downloads/route.ts
   4. components/AppDownloadsCard.tsx
   5. app/downloads/page.tsx
3) ارفع التغييرات معًا وانتظر اكتمال نشر الموقع في Vercel. ملف scripts/app-downloads.test.cjs إضافي لتشغيل الاختبارات، ومرفق كاملًا أيضًا.
4) ملف public/app-downloads.json مجهز ببيانات EXE النهائي، ويحافظ على بيانات نسختَي الماك. لا تحتاج إضافة رابط يدوي للإصدار الحالي.
5) افتح إصدارك الموجود في:
https://github.com/PSYMOHAMEDABOZAID/samee3/releases
وعدّله من Edit، أو أكمل المسودة الحالية، وتأكد من أن Tag هو:
samee3-apps
6) أرفق ملف ويندوز EXE نفسه باسمه الأصلي في منطقة:
Attach binaries by dropping them here or selecting them
الموجودة أسفل وصف الإصدار.
لا تفك EXE ولا ترفعه من Add files داخل محرر الوصف. لا ترفعه إلى ملفات Git العادية داخل public؛ مكانه Release assets.
7) احتفظ بملفَي الماك الموجودين، وأضف ملف ويندوز الثالث بجوارهما ثم Publish release أو Update release.
8) افتح:
https://samee3.vercel.app/downloads
سيظهر زر تحميل ويندوز في هذه الصفحة وفي الرئيسية بعد التحقق من الملف خلال عدة دقائق. إن ظل الإصدار Draft لن يكون متاحًا للزوار.
9) أسماء الملفات وأحجامها وبصماتها يجب أن تطابق JSON؛ الكود يبقي الزر غير متاح عند غياب الملف أو عدم التطابق بدل رابط معطوب.

الفرق بين النسخ
Windows Intel/AMD x64: ملف EXE لأجهزة الكمبيوتر بنظام ويندوز.
Mac Apple Silicon: ZIP لأجهزة الماك بمعالج M1 وما بعده.
Mac Intel: ZIP لأجهزة Apple Mac بمعالج Intel، وليس ويندوز.
Android: بطاقة APK الأصلية مستمرة كما هي مع بيانات public/android/release.json الحالية.

المصدر الكامل
Samee3-Windows-1.0.0-Source.zip يحتوي مجلد native/windows كاملًا، بما فيه ملفات البرمجة وبيانات المصحف والخطوط والأذان والأيقونة والرخص.
رفع المصدر للمستودع اختياري لتشغيل زر التحميل، لكنه مفيد للاحتفاظ بالكود. ضع المجلد داخل native/windows، ولا تستبدل package.json الخاص بجذر الموقع بملف package.json الخاص بتطبيق ويندوز.
لبناء إصدار جديد على ويندوز: ثبّت Node.js 24 وافتح Build-Windows.cmd داخل مجلد المصدر، أو نفذ npm ci ثم npm test ثم npm run dist:windows.
ملف التثبيت الجديد يظهر داخل native/windows/dist. لا ترفع node_modules أو dist إلى Git؛ ارفع EXE النهائي إلى Releases وحدّث بياناته في public/app-downloads.json وأعد نشر الموقع.
تحديثات أقسام الموقع تظهر بعد تحديث الصفحة؛ تحديث محرك التطبيق أو أيقونته المثبتة أو بياناته المحلية يحتاج إصدار ويندوز جديدًا.

الملفات النصية
Samee3-Windows-ALL-CODES.txt: ملفات البرمجة والإعدادات كاملة مع مسار كل ملف.
Samee3-Windows-OPEN-CODES.html: افتحه في المتصفح لاختيار المسار ونسخ الكود كاملًا أو تنزيله TXT.
ملفات TXT الفردية تحتوي الكود فقط، دون عناوين. عند وضعها في المشروع استخدم اسم الملف الأصلي بدون .txt.
بيانات القرآن الكبيرة والخطوط والتسجيلات ملفات أصول داخل Source.zip، ولا تُنسخ من ملف الأكواد.
