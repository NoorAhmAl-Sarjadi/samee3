# مصحف سميع — نسخة GitHub خفيفة

هذه النسخة مهيأة للرفع من واجهة GitHub بدون ملفات الروايات البديلة الكبيرة.

## تحتوي على
- واجهة Vite بسيطة.
- 6 روايات محلية: حفص، ورش، قالون، الدوري، السوسي، شعبة.
- ملف JSON واحد فعلي لكل رواية.
- خط WOFF2 محلي لكل رواية.
- تبديل الرواية من الواجهة وقراءة النص محليًا.
- الصوتيات تظل من CDN عبر الإنترنت.

## التشغيل
```bash
npm install
npm run dev
```

## الرفع إلى GitHub من المتصفح
فك الضغط عن الملف ZIP أولًا، ثم افتح مستودعك في GitHub واختر **Add file → Upload files** واسحب محتويات مجلد المشروع. لا ترفع ملف ZIP نفسه كمستودع تشغيل.

## ملاحظة
هذه ليست لوحة إدارة خادمية متعددة المستخدمين؛ التعديلات الحالية محلية في المتصفح.
