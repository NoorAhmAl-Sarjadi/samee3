# مصحف سميع

واجهة عربية مستوحاة من المرجع البصري المرسل في المحادثة: مصحف/صفحات، فهرس، روايات، مكتبة سمعية، أدوات المسلم، إشعارات، ومكتبة مقروءة.

## الروايات المحلية
تم تضمين بيانات JSON وخطوط WOFF2 للروايات:
حفص، ورش، قالون، الدوري، السوسي، شعبة.

## الصوتيات والقراء
المكتبة السمعية تستخدم واجهة MP3Quran.net API v3 لجلب جميع القراء والتلاوات والروايات، ثم تشغيل ملف السورة من خادم التلاوة المناسب.

مصدر API: https://www.mp3quran.net/ar/api/2

## تشغيل
```bash
npm install
npm run dev
```
