# مصحف سميع (SAMEE3)

منصة قرآنية متعددة الخدمات مبنية باستخدام Next.js 14 وReact وTypeScript وFirebase.

## الأقسام الموجودة

- المصحف الشريف والروايات والتظليل المصاحب للتلاوة
- المكتبة الصوتية وفهرس السور
- الأذكار وقراءتها وتشغيل التسجيلات البشرية
- كتب الحديث والمكتبة الإسلامية والتفسير
- مواقيت الصلاة والحساب الشخصي والإدارة والرسائل
- التخزين دون إنترنت باستخدام Service Worker وCache Storage وIndexedDB

## التشغيل

يتطلب Node.js 22. من جذر المستودع:

```bash
npm install
npm run audit:static
npm run test:proxy
npm run build
npm run dev
```

اختبار `test:proxy` يحتاج تثبيت حزمة `typescript` من dependencies الخاصة بالتطوير.

## نقطة مهمة للأذكار دون إنترنت

النسخة المضغوطة الأصلية احتوت على ملف عمل GitHub Actions داخل `public/data/adhkar.json` بدل نصوص الأذكار. تم استبدال الملف غير الصالح بقائمة JSON فارغة آمنة، مع إبقاء التحميل من المصدر الأساسي والاحتياطي والكاش الموثق للمستخدم. بعد رفع المشروع، مهمة **SAMEE3 Adhkar Snapshot** في **Actions** تجلب النصوص الأصلية، تتحقق منها وتثبتها في الملف المحلي؛ يلزم نجاح المهمة كي تعمل الأذكار محليًا دون زيارة المصدر الإلكتروني أولًا. تحتاج المهمة إلى صلاحية `contents: write` في إعدادات GitHub Actions.

المصدر: https://github.com/rn0x/Adhkar-json

## سير العمل الآلي

- `.github/workflows/samee3-build-check.yml`: تحقق الاستيرادات والمصادر والنحو وTypeScript والبناء.
- `.github/workflows/adhkar-snapshot.yml`: جلب بيانات الأذكار المعتمدة مع رفض تغيير أي نص سبق اعتماده دون مراجعة.
- `.github/workflows/hadith-explanations-*.yml`: مسار تحرير ومراجعة شروح الأحاديث، لم يتم تغيير محتوى الأحاديث أو ادعاء مراجعة آلية.

## ما لم يُتحقق منه في بيئة المراجعة

لم يكن تثبيت حزم npm عبر الإنترنت متاحًا أثناء إعداد النسخة. اختُبرت سلامة صياغة ملفات TypeScript/JS ومواضع الاستيراد، واختُبر مسار بيانات الأحاديث بمصادر محاكاة. لا يُعدّ ذلك بديلًا لاختبار `npm run build` الحقيقي واختبارات الأجهزة واتصال المصادر الخارجية وFirebase. راجع ملف `SAMEE3_REVIEW_AR.md`.
