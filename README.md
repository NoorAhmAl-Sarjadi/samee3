# مصحف سميع — الواجهة الذهبية

واجهة عربية للمصحف مع دعم الروايات المحلية المدمجة، القراءة والاستماع، الأدعية والأذكار، العلامات المرجعية، والإعدادات.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## الروايات الحالية

حفص عن عاصم، ورش عن نافع، قالون عن نافع، الدوري عن أبي عمرو، السوسي عن أبي عمرو، شعبة عن عاصم.

> لوحة الإدارة داخل هذه النسخة محلية للمتصفح. الإدارة متعددة المستخدمين تحتاج خدمة خلفية وقاعدة بيانات.
