# مصحف سميع — SAMEE3 Quran

منصة قرآن ويب/PWA عربية الاتجاه، مبنية بـ Next.js وReact وTypeScript، وتشمل المصحف، التلاوة، الروايات، الأحاديث، الأذكار، مواقيت الصلاة والمكتبة الإسلامية.

## التشغيل محليًا

```bash
npm install
npm run typecheck
npm run build
npm start
```

## تطوير

```bash
npm run dev
```

## قواعد المستودع

لا ترفع `node_modules` أو `.next` أو `.env` أو أي ملف يحتوي أسرارًا. ملفات إعداد Firebase الموجودة في `lib/firebase.ts` هي إعدادات عميل Firebase وليست بديلًا عن قواعد Firestore الآمنة.

## التحقق الآلي

يحتوي المستودع على GitHub Actions لتشغيل فحص TypeScript ثم Production Build عند كل Push أو Pull Request.

## المصحف والتلاوة

المصحف يعتمد على بيانات صفحات ورسم موثقين، مع طبقة تفاعلية تربط الآية بالنقر والتلاوة والتوقيت عند توفر بيانات التوقيت للقارئ المختار. الروايات التي لا تتوفر لها طبقة صفحات SVG مطبوعة في المصدر الأساسي تستخدم مصدر الرواية الخاص بها بدل استبدالها تلقائيًا برواية أخرى.
