# مصحف سميع — V4 Foundation

مشروع Vite بتصميم mobile-first يعمل بنفس الروح على الهاتف والكمبيوتر.

## المصادر
- النص القرآني: ملفات الروايات المحلية المضمنة في `public/data/riwayat`.
- الصوت والقراء والتلاوات والتوقيتات: MP3Quran API.
- التفسير الميسر: QuranEnc API.
- الأحاديث: Hadith API مفتوح المصدر (fawazahmed0) كبنية تقنية أولية مع إبقاء اسم الكتاب والمرجع.
- الأذكار: بيانات حصن المسلم من مستودع مفتوح مرخص MIT بحسب المستودع المصدر.
- مواقيت الصلاة: AlAdhan API.
- Firebase Auth + Firestore: حسابات المستخدمين، المفضلة، آخر قراءة، وإعدادات الإدارة.

## تشغيل
npm install
npm run dev

## Firebase
ضع إعدادات Firebase في `.env` أو استخدم القيم الافتراضية المضمنة في `src/firebase.js`.
لا تضع أي Secret/Service Account في الواجهة الأمامية.

## ملاحظة حقوق المحتوى
قبل الإطلاق العام، راجع شروط كل مصدر/كتاب/بيانات تريد إعادة توزيعها أو تخزينها محليًا، خصوصًا بيانات الأحاديث والأذكار والصور.
