# مصحف سميع — SAMEE3

منصة عربية مبنية على Next.js 16 وReact 19 وTypeScript وFirebase، تشمل المصحف بسبع روايات والتلاوات والأذكار والحديث والمكتبة الشرعية.

## التشغيل والنشر

يتطلب المشروع Node.js 24، بإصدار 24.12 أو أحدث داخل السلسلة 24. فك الضغط وارفع **محتويات المجلد** إلى جذر مستودع GitHub، بما فيها `.github` و`data` و`public` و`package-lock.json`. رفع ملف ZIP وحده إلى المستودع لا يشغّل التطبيق.

```bash
npm ci
npm run dev
```

للإنتاج:

```bash
npm run build
npm start
```

على Vercel: اختر Next.js وNode.js 24، وأبقِ مجلد الجذر هو المجلد الذي يحتوي على `package.json`. يتطلب التطبيق استضافة تدعم خادم Next.js؛ GitHub Pages لا يشغّل مسارات API.

**Firebase — خطوة واحدة بعد التحديث:** انشر ملف `firestore.rules` إلى مشروع Firebase الحالي من صفحة Firestore Rules ثم Publish، أو بعد تسجيل الدخول إلى حساب مالك المشروع:

```bash
npx firebase-tools@14.22.0 deploy --only firestore:rules
```

الملف `.firebaserc` يشير إلى مشروع التطبيق الأصلي `samee3-fb475`. قواعد المكتبة الجديدة مطلوبة لحفظ التقدم وإصدار الشهادات؛ رفع GitHub لا ينشر هذه القواعد تلقائيًا. عند تغيير نطاق الموقع، أضفه إلى Authorized domains في Firebase Authentication. إعدادات Firebase العامة في `lib/firebase.ts` تخص المشروع الأصلي وليست بيانات حساب إداري.

## التحديث

- صفحات السوسي والبزي: ١٢٠٨ صفحات أصلية محفوظة محليًا بصيغة متجهة، مع إزالة هوامش المصدر، وتكبير وتحريك. وضع قراءة واضح بخط كل رواية ونصها وبيانات آياتها، وحجم خط قابل للتعديل. لا تُستخدم مناطق تحديد آيات تقديرية فوق الصفحات الأصلية.
- التلاوة: مطابقة الرواية والتسجيل بدقة، واستخدام معرّف المصحف الصحيح لتوقيت الآيات، وانتظار انتهاء الانتقال قبل التشغيل، ومنع الرجوع إلى أول السورة عند فقد توقيت الآية. إلغاء الطلبات القديمة عند الإيقاف، وحفظ موضع القراءة منفصلًا عن تسجيل قديم متوقف.
- استوديو موحد للآية والآية مع التفسير والحديث والذكر: ست لوحات ألوان، ثلاثة قوالب، أربعة مقاسات، الخط والمحاذاة والهوامش والتوقيع، PNG وJPG. النص الطويل يُوزع كاملًا على بطاقات داخل ZIP.
- الأذكار: إصلاح الملف المحلي التالف وإرفاق ١٣٢ قسمًا و٢٦٧ ذكرًا من المصدر نفسه، مع الاحتفاظ بنصوصه والتحقق من بصمتها.
- المكتبة الشرعية: ثلاثة مستويات، وثمانية مجالات في كل مستوى، ومسار صفحات مستقل للمستوى والمجال والكتاب والقراءة. تقدم لكل حساب وإمكان نقل تقدم الزائر باختياره.
- شهادة واحدة لكل حساب ومستوى، باسم نهائي، بعد إتمام الكتب الثمانية. إصدار محمي بمعاملة Firestore وقواعد تمنع تكرارها أو تعديلها أو حذفها. يمكن فتح نسخة الشهادة الصادرة وحفظها لاحقًا؛ لا تصدر شهادة جديدة باسم آخر.
- الاسم مطلوب عند إنشاء الحساب وتسجيل الدخول، مع الاحتفاظ بأدوار الحساب وصلاحياته.
- إصلاح مسارات API والبناء، تحديث التبعيات، الخطوط المحلية وأيقونات التثبيت، وتفعيل فحوص GitHub Actions.

## المصادر المتاحة

الشروح مرتبطة بصفحات وقوائم YouTube حقيقية. بعض الروابط دروس افتتاحية أو شروح لمختصر الكتاب، ومبيّن ذلك في صفحة الكتاب. كتاب «تيسير التفسير» لإبراهيم القطان متاح للقراءة، ولم يُنسب إليه شرح مرئي غير متحقق منه. يوجد PDF مباشر حيث توفر مصدره؛ بقية الكتب تفتح مصدر الكتاب، ويمكن للإدارة إضافة رابط PDF أو الصوت أو ملف الفيديو المباشر من صفحة إدارة المكتبة. تنزيل فيديو YouTube يتبع إتاحة الناشر والخدمة؛ رابط المشاهدة ليس ملف فيديو قابلًا للتنزيل المباشر.

الشهادات توثق الدراسة الذاتية حسب تسجيل المستخدم للإتمام، ولا تمثل اعتمادًا دراسيًا أو إجازة علمية. عدم تكرار الإصدار مضمون داخل الحساب نفسه؛ إنشاء حساب آخر يعني سجلًا آخر.

تتوفر الصفحات والملفات التي حُفظت في المتصفح دون إنترنت. يلزم اتصال أول مرة للموارد الخارجية والتسجيلات والتفسير، واتصال لحفظ التقدم السحابي وإصدار الشهادة. بقاء المحفوظ يعتمد على مساحة الجهاز وإعدادات المتصفح.

## التحقق

```bash
npm test
npm run typecheck
npm run test:rules
npm run build
npm audit
```

`test:rules` يشغّل محاكي Firestore في مشروع `demo-samee3` ويحتاج Java 17 والإنترنت لتنزيل أدوات المحاكي لأول مرة، ولا يكتب إلى بيانات المشروع الحقيقية. بقية الاختبارات الأساسية لا تحتاج حساب Firebase. راجع `REVIEW_AR.md` لنطاق التحقق و`SOURCES.md` للمصادر.
